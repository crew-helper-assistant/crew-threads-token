Threads 長期權杖產生器

用 Threads App 產生 60 天長期存取權杖（long-lived access token）。

隱私說明：這是一個純前端工具，沒有後端伺服器。你輸入的資料只會從你的瀏覽器直接送到 Meta 官方伺服器（threads.net、graph.threads.net），不會傳到任何其他地方。App 密鑰預設不會被儲存；除非你主動勾選，否則只有 App ID 和 redirect URI 會存在這台裝置的瀏覽器本機儲存（localStorage）。

基本資料

1開啟 Threads 授權頁面

會在新分頁打開 Threads 官方授權頁。登入並同意後，瀏覽器會跳轉到你的 redirect URI（頁面可能打不開，這是正常的）。

授權網址：（填入 App ID 和 redirect URI 後顯示）

2貼上跳轉後的網址

把瀏覽器網址列上跳轉後的完整網址貼在這裡（或只貼 code 也可以）。

3交換長期權杖

先用 code 換短期權杖，再立即換成 60 天長期權杖。如果失敗，會顯示 Meta 回傳的原始錯誤方便除錯。

4你的長期權杖

記得把這串權杖貼到 Instinct 傳給你的保管庫（vault）連結，不要直接貼在聊天訊息裡。
